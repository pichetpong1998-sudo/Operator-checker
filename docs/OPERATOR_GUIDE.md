# คู่มือใช้งานสำหรับ Operator

## 1. เข้าสู่ระบบ

1. เปิดแอป Belt Check บนมือถือ (ถ้ายังไม่ติดตั้ง ดูขั้นตอนด้านล่าง)
2. กรอก **รหัสพนักงาน** และ **PIN**
3. กด "เข้าสู่ระบบ"

### ติดตั้งแอปลงหน้าจอโฮม (ครั้งแรกเท่านั้น)

- **Android (Chrome)**: เปิดลิงก์ระบบ → เมนู ⋮ มุมขวาบน → "เพิ่มลงหน้าจอโฮม"
- **iPhone (Safari)**: เปิดลิงก์ระบบ → ปุ่มแชร์ (กล่องมีลูกศรขึ้น) → "เพิ่มลงหน้าจอโฮม"

หลังติดตั้งแล้ว แอปจะเปิดแบบเต็มจอเหมือนแอปทั่วไป ไม่มีแถบ URL ของ browser

## 2. เลือกหัวสายพานที่จะตรวจ

หน้าแรกจะแสดงหัวสายพานทั้งหมด (S2C, S2B, S2A, S2, S3, S5, B1, B2, B3, C1, C2) แตะเลือกหัวที่ต้องการตรวจ

## 3. การตรวจสอบตำแหน่ง GPS (สำคัญมาก)

- แอปจะขอสิทธิ์เข้าถึงตำแหน่ง GPS — **ต้องกด "อนุญาต"** ไม่เช่นนั้นจะเปิด Checklist ไม่ได้
- ระบบจะเปิด Checklist ให้เฉพาะเมื่อคุณ**อยู่ในระยะที่กำหนดจากหัวสายพานนั้นจริง**เท่านั้น
- ถ้าขึ้นข้อความ "อยู่นอกรัศมี" → เดินเข้าใกล้หัวสายพานมากขึ้นแล้วกด "ลองตรวจสอบตำแหน่งอีกครั้ง"
- ถ้าขึ้นข้อความ "สัญญาณ GPS ไม่แม่นยำพอ" → ออกไปที่โล่งแจ้ง ไม่มีหลังคา/โครงสร้างเหล็กบังสัญญาณ แล้วลองใหม่

> ระบบตรวจสอบตำแหน่งซ้ำที่ server ทุกครั้งก่อนรับผลตรวจ แม้ผ่านการตรวจครั้งแรกแล้ว หากย้ายออกนอกรัศมีระหว่างตรวจ ระบบอาจปฏิเสธการบันทึกผลได้

## 4. กรอกผลตรวจ

สำหรับแต่ละรายการตรวจ:

- **รายการแบบ Pass/Fail/N-A**: แตะปุ่มขนาดใหญ่ PASS / FAIL / N/A
- **รายการแบบตัวเลข** (เช่น ระดับน้ำมัน): กรอกค่าตัวเลข — ถ้าค่าที่กรอกเกินเกณฑ์ที่กำหนดไว้ ระบบจะแจ้งเตือนทีมวิศวกรทันทีโดยอัตโนมัติ

### เมื่อกด FAIL

จะมีช่องเพิ่มเติมให้กรอก:
1. **คำอธิบาย** — พิมพ์หรือกด 🎤 พูดแล้วให้ระบบแปลงเป็นข้อความอัตโนมัติ
2. **ถ่ายภาพ** — กด "📷 ถ่ายภาพจุดเสีย" แล้วแตะบนรูปเพื่อวงกลมไฮไลต์ตำแหน่งที่เสียหาย

## 5. บันทึกผลตรวจ

เมื่อตอบครบทุกรายการ (หรือครบเท่าที่ตรวจได้) กด **"บันทึกผลตรวจ"** ที่ด้านล่างจอ

- **ถ้าออนไลน์**: ระบบส่งข้อมูลเข้า server ทันที
- **ถ้าออฟไลน์** (ไม่มีสัญญาณ): ระบบจะบันทึกไว้ในเครื่องก่อน แล้วขึ้นข้อความ "รอ sync อัตโนมัติ" — เมื่อมือถือกลับมามีสัญญาณ ระบบจะส่งข้อมูลเข้า server ให้อัตโนมัติโดยไม่ต้องทำอะไรเพิ่ม
- สามารถกด **"Sync ตอนนี้"** ที่หน้าแรกเพื่อบังคับ sync ทันทีเมื่อกลับมามีสัญญาณ

## คำถามที่พบบ่อย

**ถ้าตรวจเสร็จตอนออฟไลน์แล้วปิดแอปไปเลยล่ะ?**
ข้อมูลยังอยู่ในเครื่อง ไม่หาย — เปิดแอปใหม่แล้วระบบจะพยายาม sync ให้อัตโนมัติเมื่อมีสัญญาณ

**ทำไมกด FAIL แล้วบันทึกไม่ผ่าน?**
ตรวจสอบว่ายังอยู่ในรัศมีที่กำหนดของหัวสายพานนั้นหรือไม่ ระบบตรวจตำแหน่งซ้ำทุกครั้งก่อนบันทึก

**ลืม PIN ทำอย่างไร?**
แจ้ง Engineer หรือ Admin เพื่อรีเซ็ต PIN ให้ผ่านระบบ
