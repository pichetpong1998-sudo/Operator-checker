# คู่มือใช้งานสำหรับ Engineer

## 1. เข้าสู่ระบบ

เข้าผ่านเว็บเบราว์เซอร์ (คอมพิวเตอร์หรือมือถือ) ที่ `https://<โดเมนของระบบ>` แล้ว login ด้วยรหัสพนักงาน + PIN

## 2. Dashboard สถานะหัวสายพาน

หน้า Dashboard แสดง:

- **การ์ดสถานะแต่ละหัวสายพาน** (11 หัว) แบ่งเป็น:
  - 🟢 **Ready** — ผลตรวจล่าสุดผ่านทุกรายการ
  - 🟡 **Warning** — มีค่าตัวเลขเกินเกณฑ์ (threshold) แต่ยังไม่ถึงขั้น Fail
  - 🔴 **Down** — มีรายการ Fail อย่างน้อย 1 รายการในผลตรวจล่าสุด
  - ⚪ **ไม่มีข้อมูล** — ยังไม่มีการตรวจในช่วงเวลาที่กำหนด (default 8 ชั่วโมงล่าสุด)
- **ความคืบหน้าการตรวจในกะปัจจุบัน** — กี่หัวจาก 11 หัวที่ตรวจแล้ววันนี้
- Dashboard รีเฟรชอัตโนมัติทุก 1 นาที

## 3. ดูรายละเอียดผลตรวจ / ประวัติ

เรียก API `/api/v1/inspections` (ผ่านหน้า Dashboard หรือเครื่องมือภายในที่จะพัฒนาเพิ่มเติม) เพื่อดูประวัติการตรวจแยกตามหัวสายพาน/ช่วงเวลา/สถานะ

## 4. Trend ค่าตัวเลข

สำหรับรายการตรวจแบบตัวเลข (เช่น ระดับน้ำมันเกียร์) สามารถเรียกดู trend ย้อนหลังผ่าน API `/api/v1/dashboard/trends?checklistItemCode=...&beltHeadCode=...&days=30` เพื่อวิเคราะห์แนวโน้มก่อนเกิดปัญหา

## 5. Export รายงาน

จากหน้า Dashboard กดปุ่ม:
- **Export Excel** — ดาวน์โหลดผลตรวจทั้งหมดเป็นไฟล์ .xlsx (กรองตามหัวสายพาน/ช่วงวันที่ได้ผ่าน query parameter)
- **Export PDF** — ดาวน์โหลดรายงานสรุปเป็น PDF พร้อมไฮไลต์รายการ Fail/Threshold เกิน

## 6. การแจ้งเตือน Critical Fail

เมื่อ Operator รายงาน Fail หรือค่าตัวเลขเกินเกณฑ์ ระบบจะส่งแจ้งเตือนอัตโนมัติผ่าน:
- **Email** (ถ้าตั้งค่า SMTP ไว้) ไปยังรายชื่อใน `ALERT_EMAIL_RECIPIENTS`
- **LINE** (ถ้าตั้งค่า LINE Messaging API ไว้) ไปยังกลุ่ม/บุคคลที่กำหนด

หากไม่ได้รับแจ้งเตือน ให้ตรวจสอบกับ Admin ว่าตั้งค่า SMTP/LINE ไว้ครบถ้วนหรือไม่ (`docs/ENV_VARS.md`)

## 7. สิทธิ์การเข้าถึงข้อมูล

Engineer มีสิทธิ์อ่านข้อมูลทุกหัวสายพาน แต่ **ไม่สามารถ** สร้าง/แก้ไขผู้ใช้งาน, เปลี่ยนพิกัด geofence หรือดู audit log ได้ (สิทธิ์เหล่านี้จำกัดเฉพาะ Admin)
